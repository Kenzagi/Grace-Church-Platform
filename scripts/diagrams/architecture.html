Cross-cutting invariants
Sessions: stateless HMAC-signed cookie, httpOnly, SameSite=Lax, secure in production, 7-day expiry.
Roles: admin (full) · editor (read + write) · viewer (read-only) — enforced inside handlers.
Tenancy: every foreign key from the client is re-checked against the session's org before write.
Validation: Zod schemas on every input — portal URLs must be http(s), durations capped.
Audit: every mutation writes an audit row; exports and reviews are audited too.
Secrets: SESSION_SECRET required at boot — the server refuses to start without it.
